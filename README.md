# 🌿 AYUSH Startup Portal

## 🚀 Overview
The **AYUSH Startup Portal** is a streamlined platform designed to support and empower AYUSH startups. It simplifies the registration process, integrates **AI-powered document verification**, and provides **real-time status updates**. The platform fosters collaboration by offering mentorship, funding opportunities, and **role-based access** for startups, stakeholders, and investors.

🔹 **Enhanced Transparency & Efficiency** – Ensuring a seamless experience for all users.  
🔹 **Supports Innovation & Growth** – Encouraging new ideas in the AYUSH sector.  
🔹 **Accessible for Startups & Stakeholders** – Promoting inclusivity and ease of use.  

📌 **GitHub Repository**: [AYUSH Startup Portal](https://github.com/jeyachandranj/AYUSH.git)

## 🏗️ Tech Stack

### 🌐 Frontend
- ⚛️ **React.js** – Interactive and scalable UI components
- 🎨 **Tailwind CSS** – Modern styling for a responsive experience

### 🖥️ Backend
- 🚀 **Express.js** – Lightweight and fast backend framework
- 🔒 **JWT Authentication** – Secure user authentication and role-based access

### 🗄️ Database
- 🍃 **MongoDB** – Scalable NoSQL database for efficient data storage
- 🔄 **Mongoose** – Object data modeling (ODM) for MongoDB

### 🛠️ Additional Tools
- 🤖 **AI-Powered Document Verification** – Automated validation of documents
- 📡 **Socket.io** – Real-time updates on application status

## 🚀 Getting Started

### 📦 Installation
```bash
# Clone the repository
git clone https://github.com/jeyachandranj/AYUSH.git
cd AYUSH

# Install dependencies
npm install
```

### 🔧 Backend Setup
```bash
cd server
npm install

# Start the backend server
npm start
```

### 🌍 Frontend Setup
```bash
cd client
npm install

# Start the frontend
yarn start
```

---

## 🔑 Environment Variables
Create a `.env` file in the backend directory and add the following:
```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```
